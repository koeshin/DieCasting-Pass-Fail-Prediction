# Die-Casting 공정 불량 예측 및 원인 분석  

## 프로젝트 개요
본 프로젝트는 **다이캐스팅(Die-Casting) 주조 공정 데이터**를 활용하여  
제품의 불량 여부를 예측하고, 단순한 예측 성능을 넘어  
**현장에서 실제로 활용 가능한 불량 원인 단서**를 도출하는 것을 목표로 한다.

주조 공정 데이터는 **양품 비율이 약 99%**로 매우 불균형한 구조를 가지며,  
이로 인해 정확도(Accuracy) 중심 평가가 품질 관리 관점에서 의미를 갖기 어렵다.  
본 분석에서는 **F1-Score를 핵심 성능 지표**로 설정하고  
LightGBM 기반 모델링과 공정 맥락을 반영한 분석을 수행하였다.

---

## 문제 정의
### 1. 극심한 클래스 불균형
- Pass(양품) 약 99%, Fail(불량) 약 1%
- 모든 데이터를 양품으로 예측해도 높은 Accuracy가 나오는 **평가 왜곡 문제**

### 2. 중요 변수 해석의 한계
- 특정 변수 하나가 예측에 과도하게 기여
- 해당 변수는 공정 시작 전 통제 변수라기보다  
  공정 결과/상태를 반영하는 값일 가능성이 있어 **현장 적용성에 제약**

---

## 접근 방법
### 1. 평가 기준 재설계 및 전처리
- Accuracy 대신 **F1-Score**를 핵심 지표로 사용
- 결측치 처리: **KNN Imputation**
- 불균형 대응:
  - SMOTE 오버샘플링 실험
  - 최종적으로는 **예측 임계값(threshold) 최적화가 가장 효과적**임을 확인

---

### 2. EDA 및 현장 맥락 기반 파생 변수
EDA 결과를 바탕으로, 단순 센서 값이 아닌 **공정 해석이 가능한 변수**를 생성하였다.

- **초기 생산 구간(워밍업 프록시)**
  - 생산 순번 `count` 기준
  - `count ≤ 20` / `count > 20`으로 구분
- **온도 안정성 관련 변수**
  - 금형 상·하부 온도 조합
  - 냉각수 온도 패턴
- **공정 변수 상호작용**
  - 속도·온도·시간 변수의 곱 형태 파생 변수

※ 파생 변수는 예측 성능 향상뿐 아니라  
불량 원인을 **공정 관점에서 해석**하기 위한 목적을 가짐

---

## 모델링
### 사용 모델
- Logistic Regression (Baseline)
- Random Forest / Gradient Boosting
- XGBoost
- **LightGBM (주력 모델)**

### LightGBM 선택 이유
- 비선형 관계 및 변수 간 상호작용을 자동으로 학습
- 불균형 데이터에서도 안정적인 성능
- Feature importance 기반 해석 가능

---

## 실험 결과
### 실험 요약
| 실험 | 접근 방식 | F1-Score |
|---|---|---|
| Feature 변형 적용 | log / quantile / binning / interaction | 0.82 ~ 0.85 |
| SMOTE 적용 | 오버샘플링 | 약 0.82 |
| **Feature 변형 미적용 (최종)** | 원본 변수 + threshold 최적화 | **0.90** |

➡️ **LightGBM의 특성상, 과도한 피처 변형 없이  
원본 공정 변수를 사용하는 것이 가장 높은 성능을 보임**

---

## 주요 인사이트
- 불량 발생은
  - **초기 생산 구간(워밍업 이전 상태)**
  - **온도 안정화 여부**
와 밀접한 관련을 가짐
- 압력·속도 등 핵심 공정 변수는 중요하지만,
  - 워밍업 및 온도 조건이 확보되지 않으면  
    동일 조건에서도 불량 확률이 증가

➡️ 분석 결과를 통해  
**“초기 워밍업 확보 및 온도 안정화”라는 구체적인 현장 개선 방향**을 도출
